# 教學大富翁產生器（teach-monopoly）

先說想要的**地圖主題**（如台灣美食、太空探索），AI 會生成 28 格新地名＋機會／命運卡片請你確認；再上傳教材 PDF／圖片或直接貼文字，AI 按你要求的題數生成**多組題庫**（可多份教材、各做一組）；全部確認後輸出一份**單檔大富翁 HTML**——雙擊即玩，含 🎲3D 骰子、🔊音效／BGM、⏱️計時結算、📂進度匯出／載入、📜玩家收支歷程，答對才能買地／抽卡，答錯直接跳過該格。

## 目錄結構

```
teach-monopoly/
├── README.md                          ← 本說明
└── 大富翁產生器/
    ├── SKILL.md                       ← skill 主檔（AI 的工作流程，一問一答）
    ├── assets/
    │   ├── template.html              ← 大富翁遊戲模板（V5 新版介面）
    │   ├── build-monopoly.js          ← 打包腳本：設定 JSON → 可玩 HTML
    │   └── validate-monopoly.js       ← 設定驗證器
    └── references/
        ├── board-spec.md              ← 40 格固定位置表、可改／不可改欄位、價格租金規則
        ├── cards-spec.md              ← 機會／命運卡 action 種類與參數規則
        ├── quiz-spec.md               ← 題庫欄位規格與命題紅線
        ├── config-spec.md             ← 設定 JSON 欄位規格
        └── custom-regions.md          ← 模板可改區塊 vs 禁止修改區對照表
```

## 安裝：從 GitHub 下載

```bash
git clone https://github.com/kentxchang-goedutw/teach-monopoly.git
```

或到 [repo 頁面](https://github.com/kentxchang-goedutw/teach-monopoly) 按 `Code` → `Download ZIP`，解壓縮即可。

## 安裝：放到 opencode 讀得到的位置

任選一種（兩種可並存）。資料夾名稱必須和裡面的 `SKILL.md` 同層，保持 `大富翁產生器/SKILL.md` 結構不要拆散。

### 方法 A｜全域使用（所有專案都可用，推薦）

把 `大富翁產生器` 資料夾整個複製到：

```
Windows:  C:\Users\<你的帳號>\.agents\skills\大富翁產生器\
macOS/Linux: ~/.agents/skills/大富翁產生器/
```

等效位置（擇一即可）：`~/.config/opencode/skills/大富翁產生器/`、`~/.claude/skills/大富翁產生器/`。

放好後開新對話，AI 的可用 skill 清單就會出現它。

### 方法 B｜只給某個工作資料夾使用（教學、單次專案用）

把 `大富翁產生器` 資料夾整個複製到該專案底下：

```
<工作資料夾>\.agents\skills\大富翁產生器\
```

（等效：`<工作資料夾>\.opencode\skills\大富翁產生器\`）

這樣只有在該資料夾開 opencode 才會載入，不污染全域。也可以不照規格放，直接把資料夾丟在工作資料夾內，用提示詞指給 AI 看（見下方範例）。

> 檢查：`SKILL.md` 檔名必須全大寫，且開頭要有 `name`、`description` frontmatter（本 skill 已內附，勿改檔名）。

## 使用方法：範例提示詞

基本形（AI 會先問你要什麼地圖主題）：

```
使用工作資料夾中的大富翁產生器的skill，幫我做一個大富翁遊戲
```

直接指定主題（**主題可省略，省略 AI 會問你**）：

```
使用工作資料夾中的大富翁產生器的skill，做一個「台灣夜市美食」主題的大富翁
```

其他條件範例（**此段可省略，也可自行加條件**）：

```
…機會／命運卡片要跟夜市主題相關
…我有兩份教材要各做一組題庫，第一組是台灣歷史、20題
…地名要用國小三年級看得懂的詞
```

教材輸入方式三選一：① 上傳 PDF／DOCX／PPTX／MD／TXT ② 直接貼文字 ③ 給網址（AI 會抓回內容）。掃描版讀不到字時 AI 會先問你。

## 完整流程（AI 會帶你走，每次只問一件事）

1. **Q1 地圖主題**：你說主題 → AI 生成遊戲標題、28 格新地名＋價格、機會／命運卡片各 6–8 張 → **列出表格請你確認**（可改名、改價、增刪卡片）。
2. **Q2 第一組教材**：你上傳教材＋題庫名稱＋題數（如「台灣歷史、20 題」）→ AI 生成四選一題庫 → **列出統計＋抽查 3–5 題請你確認**。
3. **Q3 還有下一組嗎**：有 → 回第 2 步（第 2、3…組教材）；沒有 → 進入打包。至少 1 組題庫；只想先玩地圖也可以（無題庫時遊戲中不觸發問答）。
4. **生成 HTML**：AI 跑驗證＋打包，產出 `〈遊戲標題〉-大富翁.html`（單檔，雙擊即開，建議 Chrome / Edge 開啟）。
5. 玩法：開檔 → 選人數 → 用設定畫面選單調整初始資金／遊戲時間 → 勾選題庫 → 開始 → 擲骰子；降落未持有地產／機會／命運格先答題，**答對才能買地／抽卡，答錯跳過該格**；時間到或剩一人即結算總資產。

## 需求與疑難排解

- 產生過程需要 **Node.js**（跑驗證與打包腳本）；學生開啟 HTML 遊玩則不需要任何安裝。
- skill 沒出現在清單：確認路徑是 `…/skills/大富翁產生器/SKILL.md`、檔名全大寫、已開新對話。
- 想改地名、卡片或題庫：不用改 HTML，直接在對話中說要改哪裡（如「第5格改名為…」「第2組題庫第3題答案改為…」），AI 會更新設定重跑打包。
- 初始資金／遊戲時間：在產出 HTML 的設定畫面選單調整即可，不用在對話中指定。
